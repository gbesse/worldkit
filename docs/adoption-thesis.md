# Adoption thesis

This document separates the intended commercial advantage from the capabilities already implemented.

First audience: Indie game teams experimenting with bounded model-driven NPC behavior.

Potential accumulating asset: Reusable behavior packs, deterministic replay fixtures and engine integrations.

The README is the source of truth for the current alpha. Early publication alone does not make a market position defensible. Existing users, repeat usage and valuable integrations would be needed to establish the thesis. Open formats should make adoption easier; artificial data lock-in is not the objective.

## Next validation milestones

1. Integrate the JSON runtime with one engine such as Godot.
2. Measure live Jev latency, cost and behavior quality against scripted policies.
3. Publish replayable scenario packs and test whether players prefer the resulting behavior.
